# Public Server Log Journal

한국인터넷.한국 1부 종료 이후 서버 기록과 변경 흔적을 보관하기 위한 공개 일지 저장소입니다.

이 저장소는 특정 개인이나 기관을 단정하기 위한 공간이 아닙니다. 서버 운영자가 확인한 변경 전후 기록, 파일 정보, 스크린샷, 해시, 아카이브 링크를 정리하기 위한 기록 보관소입니다.

## GitHub Pages

GitHub 저장소를 만든 뒤 Pages 설정에서 다음처럼 배포합니다.

- Source: Deploy from a branch
- Branch: main
- Folder: /root

## 기본 구조

- `_posts/`: 공개 서버 일지 원문
- `incident-notes/`: 사건별 메모와 템플릿
- `evidence/`: 스크린샷, 해시, 백업 파일 목록 보관
- `assets/`: 스타일과 공개 리소스
